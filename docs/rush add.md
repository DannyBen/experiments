# rush add

Register a local repository.  
  
This command adds the specified path to the configuration file.

| Attributes       | &nbsp;
|------------------|-------------
| Alias:           | a

## Usage

```bash
rush add REPO PATH
```

## Examples

```bash
rush add default ~/rush-repos/default
```

## Arguments

#### *REPO*

Repository name.

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes

#### *PATH*

Path to the repository.

| Attributes      | &nbsp;
|-----------------|-------------
| Required:       | ✓ Yes
